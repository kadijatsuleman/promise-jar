# Promise Jar
A tiny installable web app (PWA). Make small promises to yourself, then mark them kept or broken. Kept promises become gold marbles in your jar; broken ones become grey. Data stays on your device (localStorage). Works offline.

## Run locally
`python3 -m http.server 8000` then open http://localhost:8000

## Deploy
Push to GitHub, then Settings > Pages > Deploy from branch `main` (root).
